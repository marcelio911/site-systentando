# Systentando - Landing Page

Este é o projeto da landing page para o Systentando, uma plataforma que reúne diversos projetos com foco em empreendedorismo, desenvolvimento pessoal e impacto social.

## Projetos incluídos

- **Zen Launcher**: Um launcher que busca diminuir o tempo de tela e procrastinação, focado em bem-estar digital.
- **Meu Nutri**: Assistente nutricional inteligente que avalia e reage às fotos dos pratos.
- **Rodada de Negócios**: Plataforma que estimula a criação e participação em novos projetos.
- **O Momento do Investimento**: Simulações e trilhas de aprendizado sobre investimentos.
- **Systentando One**: Hub central que integra todos os projetos.

## Tecnologias utilizadas

- React
- Tailwind CSS
- Lucide React (para ícones)

## Executando o projeto

1. Instale as dependências:
```
npm install
```

2. Execute o servidor de desenvolvimento:
```
npm start
```

3. Acesse `http://localhost:3000` no seu navegador.

## Estrutura do projeto

- `src/components`: Componentes React da aplicação
- `src/utils`: Utilitários e dados utilizados pelos componentes
- `public`: Arquivos estáticos
